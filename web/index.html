Filosofía de Aprendizaje

Diseñado para entender el hardware, no para memorizar sintaxis

Cuatro principios pedagógicos inquebrantables que diferencian este curso de cualquier tutorial tradicional.

1. Principio de la Escalera

El aprendizaje es estrictamente progresivo. Cada lección se apoya exclusivamente en lo enseñado antes. Cero saltos mágicos de conocimiento ni librerías "caja negra".

2. Break-First, Fix-Later

Cada característica moderna existe porque algo en el lenguaje clásico fallaba. El alumno detona un bug real en un demo intencional (Undefined Behavior, Memory Leaks, Slicing) antes de aprender la solución idiomática.

3. Modelos Mentales de RAM

Visualizamos físicamente qué ocurre en la memoria física: Stack vs Heap, direcciones hexadecimales 0x..., VTable de polimorfismo y destrucción determinista con RAII.

4. Scaffolding & Fading

Analogías intuitivas en el primer párrafo para romper el hielo, que desvanecen de inmediato hacia la terminología profesional estricta que exige la industria del software.

Evolución del Lenguaje

¿Por qué C++ Moderno (C++17/20)?

Compara la fragilidad del C++ arcaico de hace 25 años frente al enfoque idiomático y seguro de LearningCpp.

Concepto / Tarea ❌ C++ Clásico / Arcaico (C++98) ✅ C++ Moderno (C++17 / C++20) Ventaja en Producción
Espacio de Nombres using namespace std; global Prefijo explícito std:: Cero colisiones de nombres globales en proyectos grandes.
Salto de Línea std::endl (Forced Flush) Carácter '\n' directo Elimina el cuello de botella de I/O por flushes innecesarios.
Inicialización int x; (Basura residual) Uniforme int x{0}; Previene basura en RAM y conversiones estrechas destructivas.
Colecciones Dinámicas Arreglos de C int arr[N]; std::vector<T> con .at() Gestión automática de memoria contigua y límites seguros.
Gestión de Memoria Punteros crudos new[] / delete[] std::unique_ptr<T> (RAII) Destrucción determinista 100% libre de memory leaks.
Aleatoriedad rand() % N (Inseguro/Sesgado) Mersenne Twister std::mt19937 Distribución uniforme de grado criptográfico y simulación.
Quick Start

Instalación del Entorno de Compilación

Configura tu compilador con soporte completo para C++17 y C++20 en menos de 5 minutos.

Instala MinGW-w64 a través del gestor oficial MSYS2: 

# 1. Abre MSYS2 UCRT64 e instala el toolchain completo:
pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain

# 2. Verifica la versión de g++ (Debe ser >= 13.0):
g++ --version

Instala GCC y las utilidades esenciales de compilación: 

# Ubuntu / Debian
sudo apt update && sudo apt install -y build-essential gdb

# Arch Linux
sudo pacman -S base-devel gdb

# Verificar instalación:
g++ --version

Instala Apple Command Line Tools o la última versión de GCC con Homebrew: 

# Instalar Command Line Tools de Xcode:
xcode-select --install

# Opcional (Último GCC vía Homebrew):
brew install gcc

# Verificar Clang / GCC:
clang++ --version
Preguntas Frecuentes

Todo lo que necesitas saber

Resolvemos las dudas más habituales sobre el enfoque pedagógico y requisitos del curso.

¿Necesito conocimientos previos de programación para comenzar?
No. El curso inicia desde el Módulo 01 asumiendo cero experiencia previa. Se explica qué es la CPU, qué es un byte y cómo un compilador traduce instrucciones de alto nivel a código binario ejecutable.
¿Por qué se prohíbe 'using namespace std;' y 'std::endl'?
Porque en proyectos del mundo real, using namespace std; causa colisiones de nombres impredecibles, y std::endl fuerza un vaciado de buffer (*flush*) innecesario que ralentiza el rendimiento de entrada/salida hasta en un 400%.
¿En qué consiste la metodología 'Break-First, Fix-Later'?
En lugar de enseñarte una solución sin contexto, primero provocamos un fallo real (fuga de memoria, clonación en la pila, comportamiento indefinido o truncamiento) para que sientas el problema en carne propia. Luego introducimos la herramienta moderna de C++17/20 que lo resuelve elegantemente.
¿El curso es totalmente gratuito y de código abierto?
Sí. Todo el temario, lecciones, código de ejemplo, simulaciones y ejercicios están disponibles libremente en el repositorio oficial.
