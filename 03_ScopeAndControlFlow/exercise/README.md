# 🏋️ Ejercicios Prácticos — Módulo 03

Esta carpeta agrupa las simulaciones diseñadas para dominar el **Control de Flujo** y la gestión estricta del **Local Scope** en C++. Superar estos módulos garantizará tu habilidad para orquestar toma de decisiones y ciclos repetitivos en arquitecturas complejas.

## 📁 Lista de Retos

- 📂 **`E01_SistemaDeClima/`**: Implementa comprobaciones mutuamente excluyentes refactorizando lógica fracturada (`if/else`) en un sistema ambiental.
- 📂 **`E02_CalculadoraDeRangos/`**: Repara un bloque de ejecución defectuoso (Unreachable Code) ordenando correctamente evaluaciones secuenciales en una caseta de cobros.
- 📂 **`E03_RescateDeVariables/`**: Aísla y neutraliza fallos de asignación en memoria solucionando colapsos de *Scope* y la vulnerabilidad de *Variable Shadowing*.
- 📂 **`E04_SelectorDeClase/`**: Estructura el enrutamiento de atributos mediante `switch`, inyectando instrucciones de escape para prevenir fugas de flujo (*Fallthrough*).
- 📂 **`E05_ContrasenaSegura/`**: Migra un ciclo de validación de autenticaciones desde pre-comprobación (`while`) hacia post-comprobación iterativa (`do-while`).
- 📂 **`E06_CuentaRegresiva/`**: Calibra la inicialización, evaluación y mutación de un iterador determinista (`for`) solucionando un defecto *Off-By-One* crudo.
- 📂 **`E07_BuscadorDeArchivos/`**: Manipula alteraciones de flujo manual en un escáner heurístico, empleando terminaciones prematuras (`break`) y saltos de iteración (`continue`).
- 📂 **`E08_CajeroAutomatico/`**: *Implementación Final.* Orquesta una interfaz transaccional operando iteraciones perpetuas, enrutamiento estructural y protegiendo el Scope del balance financiero.

## 🛠️ Cómo hacer los ejercicios

1. Entra a la carpeta del reto de tu interés.
2. Todo reto tiene un contexto o "lore", así que **siempre lee el `README.md`** que está dentro de la carpeta antes de tocar el código.
3. Abre el archivo principal `.cpp` y sigue las instrucciones que están detalladas en los comentarios (busca los `TODO`).
4. Compila el archivo a mano usando la terminal (ej: `g++ -std=c++17 E01_SistemaDeClima.cpp -o app`).
5. Si encuentras un bloqueo arquitectónico o la terminal colapsa (ej. *Infinite Loop*), accede a la subcarpeta `solution/` y analiza el código resuelto de referencia.
