# 🛤️ Módulo 03: Arquitectura de Flujo y Aislamiento de Memoria
</div>

En este módulo, el código pasará de tener una ejecución lineal y estática a ser un sistema dinámico. Aprenderás a orquestar el flujo de control para que el software tome decisiones, repita rutinas a gran velocidad mediante iteraciones deterministas y condicionales, y, lo más importante, dominarás las reglas del aislamiento de Scope que gobiernan el ciclo de vida de la memoria local.

## 💻 Ejercicios y Laboratorio

- **🧪 Laboratorio:** Explora código práctico en la carpeta `lab/` y aprende a auditar trampas lógicas críticas (*Fallthrough*, *Infinite Loops*, *Off-By-One Buffer Overflow* y *Variable Shadowing*) en la carpeta `lab/demos/`.
- **🏋️ Ejercicios:** 8 retos de implementación en la carpeta `exercise/` diseñados para validar tu lógica (Ej. Sistemas climáticos, Enrutadores de roles, Accesos condicionales y Transacciones financieras).
