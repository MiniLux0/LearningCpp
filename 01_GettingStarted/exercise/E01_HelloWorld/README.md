# Reto E01: Hello World y Tu Primer Programa

## Contexto

Tu primer rito de paso en C++ es hacer que la computadora te salude. 

## Misión

Escribe un programa C++ completo que imprima un mensaje de bienvenida de 3 líneas en la consola.

- No uses `using namespace std;`.
- Usa el prefijo `std::cout` explícitamente.
- Usa `\n` para los saltos de línea.
