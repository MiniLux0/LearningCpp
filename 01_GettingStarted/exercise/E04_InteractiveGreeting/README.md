# Reto E04: Saludo Interactivo

## Contexto

Necesitamos un programa que interactúe dinámicamente con el usuario preguntando su nombre y edad, y luego lo salude.

## Misión

Usa `std::cin` para capturar la información en las variables correspondientes y luego imprime el saludo.
