# Reto E02: Domando los Namespaces

## Contexto

Un desarrollador junior llenó el código de errores de compilación porque usó `using namespace std;` globalmente y ahora el compilador está confundido con funciones que se llaman igual.

## Misión

Limpia el código eliminando el `using namespace std;` y arregla todas las llamadas usando el prefijo seguro `std::` explícitamente.
