# Reto E03: Secuencias de Escape

## Contexto

El arte ASCII en consola requiere imprimir comillas, barras invertidas y tabulaciones. Si los escribes directamente, el compilador explota.

## Misión

Arregla los `std::cout` usando las secuencias de escape correctas (`\"`, `\\`, `\t`, `\n`) para que el arte se imprima perfectamente.
