# Section 01 — Exercises: Getting Started Practice Problems

Hands-on practice exercises designed to consolidate your understanding of C++ program anatomy, escape sequences, namespaces, and user input/output.

---

## 📋 Exercise Index

| File Name | Topic | Problem Description |
|-----------|-------|---------------------|
| **`E01_HelloWorld.cpp`** | Program Anatomy | Write a 3-line welcome banner program using `#include <iostream>` and `main()`. |
| **`E02_EscapeSequences.cpp`** | Text Formatting | Format a tabbed quote using `\n`, `\t`, and `\"` escape sequences. |
| **`E03_Namespaces.cpp`** | Scope Resolution | Demonstrate explicit `std::` scope vs `using namespace std;` in two separate functions. |
| **`E04_InteractiveGreeting.cpp`** | User Input | Prompt the user for their name and age using `cin >>` and display a custom response. |
| **`E05_FormattedReceipt.cpp`** | Mini-Project | Build an interactive store receipt generator formatting item names and prices. |

---

## 🛠️ How to Build and Run Exercises

```bash
cd 01_GettingStarted/exercise
make
.\build\E05_FormattedReceipt.exe
```
