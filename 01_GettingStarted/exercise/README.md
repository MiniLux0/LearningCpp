# 🏋️ Ejercicios Prácticos — Módulo 01: Getting Started

Bienvenido a la sección de ejercicios prácticos del Módulo 01. Cada reto está diseñado para fijar los modelos mentales aprendidos en la teoría y entrenar tus manos en la compilación y depuración desde la terminal.

---

## 📁 Lista de Retos

1. [**E01_HelloWorld**](E01_HelloWorld/README.md) — Tu primer programa en C++. Imprime un mensaje formal de bienvenida usando `std::cout` sin atajos arcaicos.
2. [**E02_Namespaces**](E02_Namespaces/README.md) — Aislar el flujo de salida sin contaminar el espacio global con `using namespace std;`.
3. [**E03_EscapeSequences**](E03_EscapeSequences/README.md) — Formateo tabular y visual en la consola mediante secuencias de escape (`\n`, `\t`, `\"`, `\\`).
4. [**E04_InteractiveGreeting**](E04_InteractiveGreeting/README.md) — Inicialización uniforme `{}` segura y captura interactiva de datos con `std::cin`.
5. [**E05_FormattedReceipt**](E05_FormattedReceipt/README.md) — Captura de cadenas completas con espacios usando `std::getline` y generación de una tarjeta formateada.

---

## 🛠️ Cómo hacer los ejercicios

1. Entra a la carpeta del reto de tu interés.
2. Todo reto tiene un contexto o "lore", así que **siempre lee el `README.md`** que está dentro de la carpeta antes de tocar el código.
3. Abre el archivo principal `.cpp` y sigue las instrucciones que están detalladas en los comentarios (busca los `TODO`).
4. Compila el archivo a mano usando la terminal (ej: `g++ -std=c++17 E01_HelloWorld.cpp -o app`).
5. Si no sabes cómo continuar o el compilador arroja errores, entra a la subcarpeta `solution/` y revisa el código resuelto.
