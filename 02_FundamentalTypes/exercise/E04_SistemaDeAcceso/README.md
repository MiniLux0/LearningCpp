# 🪪 Reto E04: Sistema de Acceso

## 🪩 Contexto

Has sido contratado para programar el sistema de acceso de una discoteca VIP. El sistema tiene reglas estrictas de entrada usando compuertas lógicas (AND, OR, NOT) y evaluaciones de igualdad.

## 🛠️ Tu misión

1. **La edad:** Usa el operador de comparación correcto para validar que la persona tenga al menos 18 años.
2. **La lista VIP:** El cliente puede entrar si tiene boleto `||` (O) si está en la lista VIP. ¡Pero el código actual usa `=` en lugar de `==` y está sobrescribiendo la lista! Arréglalo.
3. **La validación maestra:** Para entrar a la fiesta, el cliente DEBE cumplir con la regla de edad `&&` (Y) tener acceso válido (boleto o VIP). Evalúa ambos en la variable final `puede_entrar`.
