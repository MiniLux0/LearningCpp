# 🏋️ Ejercicios Prácticos — Módulo 02

Esta carpeta contiene los retos diseñados para asimilar los conceptos teóricos de **Fundamental Types**, como la administración de memoria básica, las variables, la inicialización uniforme y los operadores de C++.

## 📁 Lista de Retos

- 📂 **`E01_TiposYMemoria/`**: Usa el operador `sizeof` para descubrir cuánto pesa cada tipo de dato en tu máquina.
- 📂 **`E02_ProteccionNarrowing/`**: Aprende a protegerte de la pérdida silenciosa de datos utilizando llaves `{}`.
- 📂 **`E03_RepartoDePizzas/`**: Arregla los bugs de un programa calculador aplicando la precedencia matemática correcta, la división para decimales y el módulo `%`.
- 📂 **`E04_SistemaDeAcceso/`**: Programa las compuertas lógicas de una discoteca VIP utilizando `&&`, `||` y esquivando la trampa de asignación `=` contra `==`.
- 📂 **`E05_Promedio/`**: Arregla la pérdida de decimales en un sistema de calificaciones utilizando el casteo seguro `static_cast<double>()`.
- 📂 **`E06_DetectiveAuto/`**: Juega a ser el compilador y elimina el abuso de `auto` para recuperar tipos explícitos en un código con "amnesia".
- 📂 **`E07_SplitTheBill/`**: Mini-proyecto integrador. Divide los gastos del departamento, verifica los datos con lógicos booleanos y evita perder centavos.

## 🛠️ Cómo hacer los ejercicios

1. Entra a la carpeta de tu interés.
2. Si el reto es un "escenario" real (como `E03` y `E04`), lee el `README.md` que está dentro de la carpeta.
3. Abre el archivo principal `.cpp` y sigue las instrucciones que están detalladas en los comentarios (busca los `TODO` o `CORRIGE AQUI`).
4. Compila el archivo a mano usando la terminal (ej: `g++ archivo.cpp -o app`).
5. Si no sabes cómo continuar o el compilador arroja errores que no entiendes, entra a la subcarpeta `solution/` y revisa el código resuelto.
