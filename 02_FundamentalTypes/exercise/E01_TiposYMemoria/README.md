# 💻 Reto E01: Tipos y Memoria

## 🎯 Contexto

Para entender cómo funciona C++, necesitas saber cómo se almacena la información físicamente en la memoria RAM de tu computadora. Cada tipo de dato tiene un "tamaño de caja" distinto.

## 🛠️ Tu misión

1. Declara cuatro variables (una de cada tipo primitivo: `int`, `double`, `char`, `bool`) usando la inicialización uniforme `{}`.
2. Imprime el valor de cada variable.
3. Utiliza el operador `sizeof` para que la computadora te imprima exactamente cuántos bytes de memoria ocupa cada una de tus variables en tu máquina.

> 💡 **Nota:** Recuerda no utilizar `using namespace std;` a nivel global.
