# 🗄️ Módulo 06: Arreglos y Vectores Dinámicos (Arrays and Vectors)

</div>

En este módulo daremos el salto fundamental desde el manejo de variables aisladas hacia **estructuras de datos en memoria contigua**. Descubriremos por qué los arreglos clásicos de C son propensos a desbordamientos catastróficos (*Buffer Overflow*), dominaremos el estándar moderno de la industria con `std::vector`, implementaremos acceso seguro a memoria mediante `.at()`, controlaremos excepciones con `try/catch`, recorreremos colecciones de forma idiomática con `range-based for`, y aprenderemos a estructurar código profesional modularizando en archivos de cabecera (`.h`) e implementación (`.cpp`).
