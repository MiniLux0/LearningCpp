# Glossary

Términos de C++ en lenguaje simple. Crece con cada sección.

---

| Término | Definición |
|---------|-----------|
| **Bit / Byte** | Bit = 0 o 1. Byte = 8 bits, unidad básica de memoria. |
| **Compiler** | Traduce código C++ a binario ejecutable. |
| **Constructor** | Función especial que se ejecuta al crear un objeto. Inicializa datos. |
| **Declaration** | Decirle al compilador que una variable existe (tipo + nombre). |
| **Expression** | Combinación de valores y operadores que produce un resultado. |
| **Function** | Bloque de código reutilizable que realiza una tarea específica. |
| **Header** | Archivo `.h` / `.hpp` con declaraciones que otros archivos pueden usar. |
| **Initialization** | Dar un valor inicial a una variable al declararla. |
| **Instance** | Objeto creado a partir de una clase. |
| **Object** | Instancia de una clase. Contiene datos y comportamiento. |
| **Operator** | Símbolo que realiza una operación (`+`, `-`, `==`, `&&`). |
| **Overflow** | Cuando un número excede el rango máximo de su tipo. |
| **Pointer** | Variable que almacena la dirección de memoria de otra variable. |
| **Reference** | Alias (nombre alternativo) para una variable existente. |
| **Scope** | Dónde existe y puede usarse una variable. |
| **String** | Cadena de texto (colección de caracteres). |
| **Variable** | Nombre que almacena un valor en memoria. |
