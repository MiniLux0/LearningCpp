## What is CS106X?

CS106X is the **honors/accelerated version of CS106B**. It covers the same topics but at roughly double the speed, with harder assignments and more advanced capstone projects.

- 🎓 **Level**: Honors / Accelerated (assumes strong CS106B-level background)
- 👨‍🏫 **Instructors**: Jerry Cain & Garrick Fernandez
- 🔗 **Official page**: [CS106X Main Page](https://web.stanford.edu/class/cs106x/)

> **Important:** This folder contains **no local downloaded files** — CS106X is used here as a reference for its handouts and assignments catalog. All materials are linked to the official Stanford website.
>
> ⚠️ **Beginner recommendation:** Finish CS106B content first. Come back to CS106X only after completing Modules 05 and 10.

---

## 📋 What CS106X Adds on Top of CS106B

| Topic (CS106X only) | What it is |
|--------------------|------------|
| **Memoization (Top-Down DP)** | Caching recursive results to avoid repeating expensive calculations |
| **Tries & Lexicons** | Prefix trees for O(L) dictionary lookups (faster than hash tables for prefixes) |
| **4-Way Priority Queues** | PQueues implemented 4 different ways (array, linked list, pointer tree, heap) |
| **Stanford 1-2-3** | Building a full spreadsheet engine — cells, formulas, dependency graphs |
