## What is CS106B?

CS106B teaches you how to **solve complex problems** using the right data structures and algorithms. While MIT 6.096 taught you the C++ language, CS106B teaches you how to *think* like a software engineer.

- 🎓 **Level**: Intermediate
- 📖 **Textbook**: *Programming Abstractions in C++* by Eric Roberts → [`textbook/CS106BX-Reader.pdf`](textbook/CS106BX-Reader.pdf)
- 🔗 **Official page**: [CS106B Course Page](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1224/)

## 📚 What You Learn

| Topic | What it means in plain English |
|-------|-------------------------------|
| **Recursion** | Solving problems by breaking them into smaller copies of themselves |
| **Backtracking** | Trying every possible solution and undoing dead ends (maze solving, Boggle) |
| **Big-O Notation** | Measuring how fast (or slow) your code runs as input grows |
| **Sorting algorithms** | Selection sort, merge sort, quicksort — and when to use each |
| **Linked Lists** | Building data structures from scratch using pointers and nodes |
| **Binary Search Trees** | Storing sorted data in a tree so you can search it in O(log n) |
| **Hash Tables** | Ultra-fast key-value lookup using hash functions |
| **Graphs** | Modeling networks and finding shortest paths (BFS, Dijkstra) |
