## 🔁 Recommended Learning Order

```
Phase 1 — Core Syntax & Memory (Modules 01–04)
  → Use: MIT 6.096 Lectures 1–4

Phase 2 — Algorithms & Problem Solving (Module 05)
  → Use: Stanford CS106B Chapters 7–10 + Assignment 3

Phase 3 — Pointers, Classes, OOP, Memory (Modules 06–09)
  → Use: MIT 6.096 Lectures 5–8 + CS106L Lectures 12–16

Phase 4 — Data Structures (Module 10)
  → Use: CS106B Chapters 13–18 + Assignments 4–6

Phase 5 — Streams & Advanced C++ (Modules 11–12)
  → Use: MIT 6.096 Lecture 10 + CS106L Lectures 5–11
```
