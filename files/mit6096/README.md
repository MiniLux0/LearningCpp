## What is MIT 6.096?

A fast-paced C++ course from MIT that teaches how computers actually work under the hood — memory, pointers, compilation, and object-oriented design. This is the **foundation course** of this repository.

- 🎓 **Level**: Beginner → Intermediate
- 👨‍🏫 **Instructor**: Geza Kovacs
- 🔗 **Official page**: [MIT OpenCourseWare 6.096](https://ocw.mit.edu/courses/6-096-introduction-to-c-january-iap-2011/)
