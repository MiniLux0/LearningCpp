# Section 03 — Exercises: Functions & Subroutines

Practice problems covering function definitions, return values, pass-by-value vs pass-by-reference, function overloading, and prototypes.

---

## 📋 Exercise Index

| File Name | Topic | Problem Description |
|-----------|-------|---------------------|
| **`E01_FunctionBasics.cpp`** | Function Calls | Write a function `greetUser(string name)` that prints a personalized greeting. |
| **`E02_PassByReference.cpp`** | Pass by Reference | Write `doubleValue(int &n)` that doubles the original value of `n`. |
| **`E03_SwapFunction.cpp`** | Swapping Variables | Write `swapNumbers(int &a, int &b)` using references to swap two numbers. |
| **`E04_Overloading.cpp`** | Function Overloading | Overload `add(int, int)` and `add(double, double)` to handle different types. |
| **`E05_HeaderPrototypes.cpp`** | Prototypes | Organize a program using forward function prototypes declared above `main()`. |

---

## 🛠️ How to Build and Run Exercises

```bash
cd 03_Subroutines/exercise
make
.\build\E03_SwapFunction.exe
```
