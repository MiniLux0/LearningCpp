# Lesson 14 — Conditionals: The `if-else` Statement

The `if-else` structure provides a fallback branch when a condition is false.

---

## 🔀 1. Syntax

```cpp
if (condition) {
    // Branch A: Executed if condition is true
} else {
    // Branch B: Executed if condition is false
}
```
