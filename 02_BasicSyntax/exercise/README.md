# Section 02 — Exercises: Basic Syntax Practice Problems

Practice exercises covering variables, data types, arithmetic operators, user input, conditionals, and loops.

---

## 📋 Exercise Problems Index

| Exercise File | Topic | Description |
|---------------|-------|-------------|
| **`E01_VariableTypes.cpp`** | Variables | Declare and initialize variables of types `int`, `double`, `char`, `bool`, `string`. |
| **`E02_NameAndAge.cpp`** | User Input | Read user name and age using `cin` and display a custom greeting. |
| **`E03_SizeofTypes.cpp`** | Memory Sizes | Print the memory size in bytes of primitive types using `sizeof`. |
| **`E04_FloatPrecision.cpp`** | Floating-Point | Format floating-point numbers using `<iomanip>` precision. |
| **`E05_IntegerDivision.cpp`** | Arithmetic | Demonstrate integer division truncation vs floating-point division. |
| **`E06_CharASCII.cpp`** | ASCII Operations | Read a character from keyboard and print its numeric ASCII value. |
| **`E07_GradeCheck.cpp`** | Conditionals | Evaluate student test score and print Pass/Fail status. |
| **`E08_AgeClassifier.cpp`** | `if-else if-else` | Classify user age into Child, Teenager, Adult, or Senior citizen. |
| **`E09_CompareNumbers.cpp`** | Relational Logic | Compare two numbers and determine the maximum value. |
| **`E10_SimpleCalculator.cpp`** | `switch-case` | Interactive console calculator performing `+`, `-`, `*`, `/` based on user operator input. |

---

## 🛠️ How to Build and Run Exercises

```bash
# Navigate to the exercises directory
cd 02_BasicSyntax/exercise

# Build all exercise programs
make

# Run any exercise (e.g., E10 Calculator)
.\build\E10_SimpleCalculator.exe
```
