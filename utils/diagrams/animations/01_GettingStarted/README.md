# Getting Started Animations

This folder contains the Manim scripts for **Module 01: Getting Started**.

Each script generates a single scene (`.gif`) used in the theory lessons.
Run them using the standard module export logic (running the file directly from Python).

## Contents
- `l01_pipeline_manim.py`: The C++ compilation pipeline.
- `l02_namespaces_manim.py`: Namespace and symbol collisions.
- `l03_flush_manim.py`: Stream buffer flushing differences (`endl` vs `\n`).
- `l04_io_manim.py`: Stream extraction via `cin`.
- `l05_profile_manim.py`: Example text-based profile app flow.
