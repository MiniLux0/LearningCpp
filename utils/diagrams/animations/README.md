# 🎬 Animaciones (Manim)

Este directorio contiene los scripts de Python que generan animaciones `.gif` utilizando la librería `manim`.

## 📂 Protocolo de Organización
Los scripts DEBEN agruparse estrictamente en subdirectorios correspondientes a su módulo objetivo (ej., `05_RecursionAlgorithms/`).

## ⚙️ Protocolo de Ejecución
Cada script en estos subdirectorios DEBE terminar con el Bloque de Ejecución dinámico definido en `SKILL.md`. Este bloque calcula dinámicamente la carpeta de salida correcta `theory/assets/` al recorrer el árbol de directorios, asegurando que un script colocado en `06_Pointers` exporte automáticamente su `.gif` a `../../../../06_Pointers/theory/assets`.

**No "hardcodees" (escribas en duro) las rutas.**
