### 4. Stanford CS106L — Standard C++ Programming
- **Official Web**: [Stanford CS106L Course Site](http://web.stanford.edu/class/cs106l/)
- **Syllabus & PDF Analysis**: 📄 [`files/cs106l/README.md`](files/cs106l/README.md)
- **Local Materials**: [`files/cs106l/`](files/cs106l/)
- **Why this course?**: Deep dive into Modern C++ features (C++11, C++17, C++20), uniform initialization, stream states, STL containers, custom iterators, function templates, lambdas, const-correctness, operator overloading, Special Member Functions (Rule of 0 / 3 / 5), Move Semantics (`std::move`), RAII, and smart pointers (`std::unique_ptr`, `std::shared_ptr`).
