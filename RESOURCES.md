# Resources & Academic Stack

Top-tier academic resources utilized to build this learning plan for C++, Algorithms, and Data Structures.

## 🏛️ Academic Courses & Sources

### 1. MIT 6.096 — Introduction to C++ (IAP 2011)
- **URL**: [MIT 6.096 OCW Page](https://ocw.mit.edu/courses/6-096-introduction-to-c-january-iap-2011/)
- **Local PDFs**: `files/lectures/` and `files/assignments/`
- **Why this course?**: To master standard C++ syntax, GCC compilation pipeline, pointers, classes, and manual memory management (`new`/`delete`).

---

### 2. Stanford CS106B — Programming Abstractions in C++
- **Reference URLs**:
  - [CS106B (Summer Quarter)](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1268/syllabus)
  - [CS106B (Winter Quarter - Keith Schwarz & Neel Kishnani)](https://web.stanford.edu/class/archive/cs/cs106b/cs106b.1224/syllabus)
- **Official Textbook**: Eric Roberts — *Programming Abstractions in C++* (saved at `files/CS106BX-Reader.pdf`).
- **Why this course?**: To transition from "writing code" to solving complex problems using **Recursion**, **Backtracking**, **Big-O Notation**, **Sorting/Searching Algorithms**, **Linked Lists**, **BST Trees**, and **Hash Tables**.

---

### 3. Stanford CS106X — Programming Abstractions in C++ (Honors / Accelerated)
- **Reference URLs**:
  - [CS106X Main Page](https://web.stanford.edu/class/cs106x/)
  - [CS106X Handouts Page](https://web.stanford.edu/class/cs106x/handouts.html)
  - [CS106X Assignments Page](https://web.stanford.edu/class/cs106x/assignments.html)
- **Instructors**: Jerry Cain & Garrick Fernandez.
- **Why this course?**: For an accelerated pace, high-performance coding challenges, memory optimization, and real-world projects.
